# Amélioration des cartes de chat Delta Green

Ce module améliore l'apparence des cartes de chat du système **Delta Green: The Role-Playing Game** dans Foundry VTT.

Il modifie leur **présentation visuelle** et certains libellés affichés, sans modifier les règles, les jets de dés ni les calculs du système Delta Green. Les boutons d'action natifs sont conservés.

## Compatibilité

- **Foundry VTT minimum : v14**
- **Foundry VTT utilisé pour les vérifications : v14.370**
- **Système requis : Delta Green**

## Fonctionnement

Le module conserve le moteur de Delta Green et applique un habillage spécifique aux cartes du chat, notamment :

- jets de compétences et résultats normaux ou critiques ;
- attaques et boutons natifs de dégâts / létalité ;
- jets de dégâts, perforation et résultats de létalité ;
- pertes de SAN ;
- marquage et amélioration des compétences ;
- messages de ressources (épuisement, stimulants, repos) ;
- tirage des caractéristiques lors de la création d'un Agent.

Les fonds varient selon le résultat ou le type de carte. Les libellés propres au module sont localisés via les fichiers de langue ; les textes produits directement par le système ne sont pas tous traduits par ce module. Le détail dépliable des dés est masqué visuellement.

## Langues

Les fichiers de traduction du module couvrent les langues déclarées par le système : `ca`, `cn`, `de`, `en`, `es`, `fr`, `ja`, `pl`, `pt-BR`, `sv` et `uk`.

## Installation et mises à jour

Après publication de la release GitHub, le module peut être installé via Foundry VTT en utilisant l'URL du manifeste :

`https://raw.githubusercontent.com/ctotone/evil-deltagreen-card/main/module.json`

Les téléchargements sont associés aux releases GitHub. Chaque release doit fournir une archive **`evil-deltagreen-card.zip`** contenant le dossier `evil-deltagreen-card/` ; le manifeste de la branche `main` doit correspondre à la release publiée.

- **Dépôt officiel :** https://github.com/ctotone/evil-deltagreen-card
- **Releases / changelog :** https://github.com/ctotone/evil-deltagreen-card/releases
- **Signaler un problème :** https://github.com/ctotone/evil-deltagreen-card/issues

## Informations importantes

Ce module est une amélioration visuelle communautaire indépendante. Il ne remplace pas le système Delta Green. Les autorisations et la visibilité des messages restent sous le contrôle de Foundry VTT et du système.
